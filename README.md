# QQ群管插件 v4.1

基于 AstrBot 框架开发的QQ群管理插件，支持分群模式、分群管理员、数学/随机验证、主人管理等功能。需配合 AstrBot Joker 插件进行 SCUM 授权。

## ✨ 功能特性

### 🔒 授权系统
- 与 AstrBot Joker 插件共用授权文件
- 群聊需要 SCUM 授权才能使用群管功能
- 支持授权时间限制
- `/查看授权` - 查看当前群的授权状态

### 📝 审核系统
- 数学验证（加减乘除运算，可配置尝试次数）
- 随机ID验证（4-5位验证码）
- 手动审核（同意/拒绝入群申请）
- 验证失败自动踢出（可选）

### 🚫 黑名单系统
- 用户黑名单
- 黑名单用户发言自动检测并撤回
- `/拉黑 <QQ> [理由]` - 拉黑用户
- `/删黑 <QQ>` - 移除黑名单
- `/清空黑名单` - 清空黑名单
- `/查看黑名单` - 查看列表

### 🔇 禁言系统
- 单人禁言（秒/分/时/天）
- 永久禁言
- 全体禁言/解禁
- 快捷禁言命令
- 定时禁言（时间段自动禁言）
- 关键词禁言

### 👢 踢出系统
- 普通踢出
- 连带踢出（踢出用户及其邀请成员）
- 踢出记录查询
- 自动撤回被踢用户的所有发言

### 🗑️ 撤回系统
- 按数量撤回
- 按用户撤回（可撤回用户所有消息）
- 按消息ID撤回
- 机器人自动撤回自己的消息（可设置撤回时间）

### 📢 欢迎系统
- 自定义欢迎语
- 欢迎功能开关
- 格式：@用户 加入群 欢迎语

### 🤖 自动回复
- **关键词回复**：触发词回复（精准/模糊匹配）+ 冷却时间限制
- **特定用户回复**：特定用户专属回复（无冷却限制），支持三种形式
  - 形式1：只@用户（用户发言时自动@）
  - 形式2：只回复消息（用户发言时自动回复消息）
  - 形式3：@用户+消息（用户发言时@并回复消息）
- 支持@用户提及

### 📊 统计系统
- 每日签到（连续签到奖励）
- 积分排行榜
- 个人信息查询
- 群统计概览

### ⏰ 定时消息
- 添加定时消息
- @全体成员定时消息
- 查看/删除消息

### 🔒 权限系统
- **机器人主人**：所有命令（所有群）
- **群管理员/群主**：群内所有命令、管理分群管理员
- **分群管理员**：禁言、踢出、撤回、黑名单等
- **普通用户**：签到、排行榜、我的信息

### 📋 群白名单与过滤群
- **群白名单**：白名单中的群不受任何功能限制，无需授权
- **过滤群**：这些群不会收到自动回复和欢迎消息

## 🔐 授权说明

本插件使用 **AstrBot Joker** 插件的授权文件，需要通过 **SCUM 授权** 后才能使用群管功能。

### 授权文件位置
```
数据目录/plugin_data/auth/auth.json
```

### 授权方式

1. **卡密激活**（通过 Joker 插件）：
   ```
   /激活卡密 <卡密>
   ```

2. **手动授权**（仅管理员）：
   ```
   /群组授权 <群号> <天数>
   ```

3. **白名单群**（不受授权限制）：
   ```
   /添加群白名单 <群号>
   ```

### 授权检查优先级

1. ✅ **机器人主人** - 自动通过，不受任何限制
2. ✅ **白名单群** - 自动通过，不需要验证
3. ✅ **非群聊环境** - 自动通过（私聊等）
4. ✅ **授权群** - 通过 Joker 插件验证

### 未授权提示

当群聊未授权时，使用群管功能会显示：
```
❌ 本群尚未授权，请联系机器人主人进行 SCUM 授权
```

### 授权验证流程

```
用户使用命令
    ↓
检查是否是机器人主人？
    ↓ 是 → 允许使用
    ↓ 否
检查群是否在白名单？
    ↓ 是 → 允许使用
    ↓ 否
检查是否是非群聊环境？
    ↓ 是 → 允许使用
    ↓ 否
检查 astrbot_plugin_joker 授权文件
    ↓ 已授权 → 允许使用
    ↓ 未授权 → 显示错误提示
```

## 🚀 安装说明

1. 将插件文件夹放入 AstrBot 的 plugins 目录
2. 重启 AstrBot 服务
3. 通过 AstrBot Joker 插件为群授权（或添加白名单）
4. 设置机器人主人（可选但推荐）：
   ```
   /添加主人 你的QQ
   ```
5. 在群内使用 `/群管菜单` 查看命令列表

## 🔒 权限说明

| 用户类型 | 权限范围 |
|----------|----------|
| 机器人主人 | 所有命令（所有群），不受授权限制 |
| 群主/群管理员 | 群内所有命令（可管理分群管理员），需授权 |
| 分群管理员 | 群管理功能（禁言、踢出、撤回等），需授权 |
| 普通成员 | 仅普通命令（签到、排行榜、我的信息） |
